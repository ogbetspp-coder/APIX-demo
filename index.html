What it takes to adopt
  • An off-the-shelf R5 FHIR server — HAPI, Smile CDR, Azure Health Data Services, AWS (note: AWS HealthLake is R4).
  • Map your local terms once via ConceptMap — then $translate does the crosswalk for every submission.
  • SMART Backend Services OAuth2 — standard machine-to-machine authentication.
  • The standards are published — HL7 APIX + PQI, both FHIR R5. No bespoke protocol to invent.
